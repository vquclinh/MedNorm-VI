## 3. Real adapter implemented

New canonical module **`src/mednorm_vi/data_engine/vietmed_ner.py`** (`ADAPTER_VERSION =
vietmed-adapter-v1`), reusing the repo's `_token_offsets`/BIO conventions — no parallel
schema. It provides:

- `load_vietmed_mapping()` — reads `configs/resources/label_mappings/public_ner/vietmed_ner_v1.yaml`;
  concrete map is `{DRUGCHEMICAL: MEDICATION}` (**MAP_APPROXIMATE**, kept approximate).
- `resolve_bio_columns()` — resolves exactly one **word** column (candidates `words`,
  `tokens`) and one **BIO-string tag** column (candidates `labels`, `ner_tags`, `tags`) by
  name **and type**: only a `list<string>` column qualifies as the BIO-tag column, so
  VietMed's int-id `tags` is correctly skipped in favour of the string `labels`. Fails
  (`VietMedSchemaError`) on a missing or ambiguous word/tag column. The resolved names are
  recorded in the preprocessing manifest (`resolved_columns`).
- `classify_row()` — authoritative deterministic policy: **empty row → EXCLUDE**;
  **words/tags length mismatch → HUMAN_REVIEW_REQUIRED** (fails the run — see below);
  **orphan `I-` → DETERMINISTIC_REPAIR**; otherwise **ACCEPT_AS_IS**.
- `convert_rows()` — decoded rows → canonical examples with half-open `[start, end)` offsets,
  guaranteeing `text[start:end] == entity.text`; preserves source split + record id + original
  labels; applies the mapping; **never reads audio**; deterministic. Returns an aggregate
  repair/exclusion summary (no raw clinical text).
- `write_artifacts()` — writes the clearly-named tree (see §4); **fails fast (no artifact
  written) if `offset_invalid != 0` OR any row is HUMAN_REVIEW_REQUIRED** (words/tags
  mismatch); records schema/adapter/mapping versions + hashes, source hashes, resolved
  columns, row/accept/repair/exclude/human-review counts, per-label/type/mapping-status
  counts, JSONL sha256, repo commit, notebook, `audio_excluded: true`.
- `load_vietmed_artifacts()` — returns examples only if the manifest is present **and** its
  recorded JSONL sha256 matches on disk (else raises — no silent fallback); returns `None` if
  absent.
- `read_vietmed_parquet()` — the **only** pyarrow-dependent step (Colab); reads
  the **resolved** word + BIO-string tag columns **only** (audio never read; via
  `resolve_bio_columns` on the Parquet schema); fails fast on missing files or
  missing/ambiguous columns.
